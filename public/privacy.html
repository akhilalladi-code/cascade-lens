Privacy statement

Last updated: 17 November 2026

CascadeLens is a browser-based CSS debugging tool. This statement describes the behavior of the application itself; it does not replace the privacy terms of the hosting provider.

Source files and workspace content

HTML and CSS files selected for import are read by your browser. The application does not provide an application backend or upload endpoint for those files. Your current editor contents are held in page memory and are not saved automatically. Refreshing or closing the page can discard unsaved work.

Accounts and analytics

The application does not require an account, password, payment information or API key. No application analytics or advertising tracker is intentionally included in the inspected application source.

Hosting provider

The application is hosted using GitHub Pages. When you visit the site, GitHub may process technical request information under its own privacy practices. Review GitHub's Privacy Statement for details.

Contact and questions

For questions, bug reports or privacy-related requests concerning this project, use the project issue tracker. Do not include private source code or personal information in a public issue.

Changes

This statement may be updated when application behavior changes. Check this page for the latest version.
